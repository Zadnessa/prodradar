МТС проверен после фиксации .4: найдено9/10 (90%) без FP. Пропуск —
пресейл с полным циклом реализации проекта, не техническое проектирование.
Версия .5 добавляет company/title + две цитаты обязанностей и получает10/10.
Предыдущая оценка сохранена в mts_native_before_alias.json; после исправления
МТС является calibration. Технический presale VK, CX-аналитика и продуктовая
стратегия остались отрицательными примерами.

Повторение: source_pool → shadow enrichment известных/близких/native
кандидатов → разметка новых названий по функциям до вывода classifier →
проверка FN/FP → точный company alias → регресс положительных и отрицательных
примеров → откат/возврат guards и aliases → cached collect. Не копировать
метку снятого или переписанного объявления: новые IDs/title отмечаются unaudited.
Для остальных категорий ещё нет полного reference audit; отдельно доступны
широкий пул, решения и native metadata. Нулевые пропуски только на title gold
не должны подменять эту недостающую проверку.

Проверка предыдущей публикации: `/start` в @ProdRadar_bot проверен на8 доставленных project
карточках; `/settings` HTTP200. TEST core содержит374 active:248 project,
132 bizdev,6 пересечений, description374/374. Это объём классифицированной
выборки;34 выбранных названия широкого пула отсутствуют в title gold.
Купер unavailable403 не включён в успешное покрытие. Подробный
[снимок метрик](test_role_slice_metrics.json) сохраняет excluded/unknown IDs,
ошибки, названия и состояние live-проверки, без реквизитов.

не включён. Технический blacklist на этом срезе не меняет результат:
это отсутствие доказанной пользы на данной выборке, а не доказательство
его ненужности на новых названиях. Counts абляции не являются числом
уникальных реальных вакансий: gold содержит регрессионные случаи.
